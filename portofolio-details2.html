FPS SHOOTING GAME UNITY WINDOWS

VOCAPLAY

Players interact with a retro pixel world where visual image prompts are presented on screen. To progress through stages and earn rewards, players must correctly pronounce the target vocabulary associated with each image in their selected language.

DOWNLOAD GAME View Source App in Github

THE FEATURES & VISION

Voice Recognition System

Real-time speech input analysis that evaluates and corrects player pronunciation.

Multilingual Support

Four selectable language options including Arabic, English, Sundanese, and Javanese.

Live Camera & Audio Feedback

Integrated live camera feed alongside instant audio-visual response indicators for correct and incorrect answers.

Project Goal

Created for educational psychology study to assist in language acquisition, speech therapy, and auditory memory retention.
