SIMPLE INTRO
GAME

Players control a 2D avatar to walk around a stylized city map and visit various buildings representing different sections of the developer's profile. Stepping into designated interaction zones opens interactive UI pop-ups that display detailed background information.

PLAY GAME View Source Code in Github

THE FEATURES & VISION

RPG Character Movement

Smooth top-down grid navigation using standard WASD or arrow key controls.

Interactive Zone Triggers

Proximity-based interaction system that seamlessly triggers modal pop-ups.

Map Exploration Nodes

Custom town environment featuring dedicated locations for developer origin, education, experience, and GitHub repositories.

Project Goal

Serves as an interactive gamified bio and web portfolio designed to replace static traditional resumes with an engaging exploration experience.
